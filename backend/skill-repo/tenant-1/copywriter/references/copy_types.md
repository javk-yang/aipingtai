# 文案类型结构库 (Copy Type Templates)

本文件为 Mode A 创作与 Mode B 跨渠道改写提供各渠道的结构模板与格式要点。生成前先按用户指定的渠道取对应模板；用户未指定渠道时，默认按"小红书种草文"处理，或询问渠道。

---

## 1. 小红书种草文

**适用**：美妆、零食、数码、家居、穿搭、职场好物、探店。
**结构**：吸睛标题 → 开篇钩子(1–2句共鸣/反差) → 正文(分点+emoji小标题) → 真实体验/证据 → 结尾CTA + 话题标签。
**标题公式**（任选）：
- 痛点+方案："xxx总是xxx？这招救了我"
- 数字+结果："3个被低估的xxx，第2个绝了"
- 身份+种草："打工人必入的x件神器"
- 避坑："别再乱买xxx了，踩过坑才懂"
**字数**：正文 300–600 字。
**格式要点**：每段 1–2 个 emoji；3–8 个话题标签，结构为 `#品类词 #场景词 #情绪词`（如 `#便携咖啡机 #出差好物 #打工人续命`）；避免硬广感，用"亲测/真实体验"口吻。
**示例片段**：
> 标题：出差党续命神器！这咖啡机让我在酒店也能喝到浓缩☕
> 正文：以前出差最怕没咖啡喝，酒店的速溶真的将就。直到带了这台……
> 结尾：同款出差党评论区扣1，我把购买链接放橱窗啦～ #便携咖啡机 #出差好物 #咖啡控

## 2. 抖音 / 视频号口播脚本

**适用**：知识分享、产品种草、品牌故事、活动预热。
**结构**：分镜表（序号 / 画面建议 / 逐字稿 / 时长 / 音效）。
**黄金5秒钩子**（任选）：反常识、抛问题、亮结果、戳痛点、给冲突。
**正文骨架**：钩子 → 痛点放大 → 解决方案 → 证据/对比 → 利益点 → CTA。
**时长档**（字数参考）：30s ≈ 80–100 字；60s ≈ 180–220 字；90s ≈ 280–320 字。
**格式要点**：逐字稿用口语短句，标注停顿；每 15–20 秒一个情绪转折点；结尾明确口头CTA（"点个赞""左下角看看"）。
**示例分镜**：
| 镜 | 画面 | 逐字稿 | 时长 |
|----|------|--------|------|
| 1 | 主角举咖啡机 | 出差住酒店还喝速溶？你亏大了。 | 0–5s |
| 2 | 演示一键出浓缩 | 这台一键出浓缩，比门店还不差。 | 5–15s |
| 3 | 展示成品 | 颜值高放哪都不违和，出差党直接封神。 | 15–25s |
| 4 | 指左下角 | 同款在左下角，懂的都懂。 | 25–30s |

## 3. 微信公众号文章

**适用**：品牌长文、行业观点、活动招募、干货分享。
**标题**（≤26字为佳）：悬念式、数字式、冲突式、共鸣式。
**开头**：故事 / 问题 / 数据钩子，前 3 行留住人。
**正文**：小标题分段，每节"一个论点 + 一个案例/数据"。
**结尾**：金句收束 + "关注/在看/留言"CTA。
**字数**：干货 1200–2000；观点 800–1500。
**示例标题**：
> 《靠这3个动作，我们把复购率拉到了47%》
> 《别再迷信"用户第一"了，真正赚钱的品牌都在做这件事》

## 4. 电商详情页 / 商品卖点

**适用**：淘宝/京东/抖音小店商品描述、主图文案、五点描述。
**FAB 五要素**：Feature(属性) → Advantage(优势) → Benefit(利益) → Proof(证明) → CTA。
**主图文案**：一句话卖点（slogan 式，≤15字）。
**五点描述**：每条"利益点(加粗) + 一句证据"，不写空话。
**示例**：
> 主图：一键浓缩，出差也能喝门店级咖啡
> 五点：① 真浓缩不将就——19bar 高压萃取，油脂满满 ② 巴掌大好携带——仅380g，塞包就走 ③ ……

## 5. 品牌 slogan / 品牌语

**适用**：品牌主张、产品口号、活动主题。
**类型**：主张型（"敢不同"）/ 功能型（"充电5分钟，通话2小时"）/ 情感型（"多一些陪伴"）/ 对话型（"你好，未来"）。
**字数**：2–12 字，易记易传播；一次给 3–5 条备选，标注各自调性。
**方法**：动词开头、对仗押韵、口语化、制造反差。
**示例备选**：
> ① 随身一杯，处处是咖啡馆（场景型）
> ② 一键浓缩，出差不将就（功能型）
> ③ 把门店级咖啡，装进包里（主张型）

## 6. 朋友圈 / 微博短文案

**适用**：私域种草、活动预告、日常互动。
**字数**：朋友圈 ≤ 80 字；微博 ≤ 140 字。
**结构**：一句话钩子 + 轻证据 + 弱CTA/互动提问。
**格式**：可配 1 张图说明；用换行制造呼吸感；emoji 1–2 个。
**示例**：
> 出差第3天，靠这台小咖啡机续命☕ 酒店速溶真的回不去了。同款放评论，出差党自取～

---

## 7. 营销邮件 / EDM

**适用**：新品通知、会员关怀、活动邀约。
**主题行**（≤20字）：利益 / 紧迫 / 好奇，决定打开率。
**结构**：称呼 → 一句话价值 → 展开(2–3点) → CTA按钮文案 → 落款。
**避雷**：别全是促销，先给读者一个打开理由；CTA 文案具体（"领取专属券"而非"点击这里"）。
**示例主题**：
> 《专属福利｜你的出差咖啡搭子到了》
> 《3天后结束｜这份续命清单请查收》

---

## 8. 信息流广告文案（投流）

**适用**：巨量/腾讯/小红书信息流投放。
**结构**：主标题(痛点/利益) + 副标题(信任) + 描述(卖点) + CTA。
**要点**：前 3 词抓人；利益前置；限时/稀缺用语需合规（避免虚假紧迫）；落地页与文案一致。
**示例**：
> 主：出差喝不上好咖啡？
> 副：便携浓缩机，门店级口感
> 描：一键出油脂，380g 塞包就走
> CTA：立即了解

---

## 9. 海报文案 / 通用短文案

**适用**：活动海报、首页 banner、落地页主视觉。
**结构**：主标题(slogan式) + 副标(支撑句) + 利益点(≤3个) + 行动指令。
**字数克制**：主标 ≤ 12 字，整体一眼读完。
**示例**：
> 主：出差也要好好喝咖啡
> 副：便携浓缩，门店级口感随身带
> 点：①一键出浓缩 ②380g 轻巧 ③颜值在线
> 行动：扫码带走你的咖啡搭子

## 通用短文案兜底骨架
