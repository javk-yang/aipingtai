# 语气调性库 (Tone & Voice)

创作定调（Mode A）与改写换风格（Mode B）时读取。先判断受众，再选调性，最后落到字词与节奏。

## 调性矩阵

1. **亲切朋友**（种草 / 私域）
   - 适用：小红书、朋友圈、社群、客服
   - 特征：像闺蜜/哥们推荐，"真的""亲测""绝了""咱"
   - 避雷：说教感、书面长句

2. **专业权威**（B2B / 测评 / 方案）
   - 适用：行业文章、数码测评、企业方案
   - 特征：数据驱动、克制、结论先行、术语适度
   - 避雷：情绪化、夸张、无依据的断言

3. **热血激情**（运动 / 国货 / 创业）
   - 适用：品牌宣言、活动预热、招募
   - 特征：短句、感叹、口号感、"冲""干"
   - 避雷：空洞喊口号而无支撑

4. **文艺治愈**（生活方式 / 文旅 / 茶香）
   - 适用：民宿、茶、香薰、慢生活品牌
   - 特征：意象、留白、慢节奏、感官描写
   - 避雷：矫情、堆砌辞藻

5. **幽默搞怪**（年轻向）
   - 适用：梗图文案、年轻品牌、互动内容
   - 特征：梗、反差、自嘲、意外转折
   - 避雷：冒犯、硬凹、低俗

6. **理性测评**（数码 / 家电 / 护肤成分）
   - 适用：参数党内容、对比评测
   - 特征：参数、对比、利弊都讲、给结论
   - 避雷：只夸不提短板、模糊数据

7. **高端克制**（奢侈 / 科技旗舰）
   - 适用：高端产品、品牌大片
   - 特征：少即是多，名词 > 形容词，留白与节奏
   - 避雷：促销腔、堆砌形容词

8. **种草安利**（美妆 / 零食 / 母婴）
   - 适用：带货、直播间话术
   - 特征：感官词（香/糯/润/上头）、具体细节、使用场景
   - 避雷：虚假夸张、无依据的功效

## 受众映射

| 受众 | 推荐调性 | 切入点 |
|------|----------|--------|
| Z世代 | 幽默 / 梗 / 反差 / 口语 | 共鸣、玩梗、不端着 |
| 宝妈 | 亲切 / 实用 / 安全 | 省心、安全、孩子 |
| 职场白领 | 专业 / 效率 / 解压 | 时间、品质、松弛感 |
| 银发群体 | 通俗 / 信任 / 简单 | 大字、大白话、安心 |
| B端决策 | 专业 / ROI / 案例 | 成本、风险、结果 |

## 术语度

- **圈内受众**（玩家、从业者）：可用术语显专业，但关键处仍要给一句人话解释。
- **大众受众**：用大白话；一个必要术语配一句解释，不炫技。

## 避雷红线

- **广告法绝对化用语**：最、第一、国家级、唯一、顶级、极致、首选——无合规依据禁用。
- **医疗/功效违规承诺**：减肥、治病、抗炎、增高等需资质，无资质不写。
- **冒犯/歧视/阴阳怪气**：保持尊重，不踩性别/地域/职业雷。
- **AI 套话**：砍掉"首先/其次/综上所述""值得一提的是""在当今社会""毋庸置疑""总而言之"，改口语短句。
