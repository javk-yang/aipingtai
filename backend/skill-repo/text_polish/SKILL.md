当用户请求翻译、润色、改写或美化文案时使用本技能。本技能为纯提示词技能，不调用任何工具。

## 执行步骤

1. 识别用户意图：翻译（跨语言）、润色（优化表达）、改写（换风格）或扩写（补充内容）。
2. 翻译场景：保留原文语气与专业术语；中英互译时避免生硬直译。
3. 润色场景：优化句式与用词，消除冗余与口语化杂质，保持原意不变。
4. 改写场景：按用户要求的风格（正式/活泼/简洁/文艺）重写，不偏离事实。

## 回复模板

- 输出润色后的文案主体，配一句简短说明（做了什么调整）。
- 若原文存在明显语病或歧义，先指出再给出修改版。

## 边界

- 不做事实核查，不主动补充原文没有的信息。
- 翻译敏感或专业内容时提示「可能存在语境偏差」。
