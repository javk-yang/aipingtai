当用户请求单位换算时使用本技能。典型场景：长度（米/厘米/千米/英尺/英寸）、重量（千克/克/斤/磅/盎司）、温度（摄氏度/华氏度）、面积（平方米/平方千米/亩/公顷）。

## 执行步骤

1. 从用户输入中提取「数值 + 源单位 + 目标单位」三元组，无法确定目标单位时按常见习惯推断（如「6 米是多少厘米」目标为厘米）。
2. 调用 `unit_converter` 工具，参数格式：
   - `value`：数值（浮点或整数）
   - `from_unit`：源单位（小写英文标准名，如 `meter` / `kilogram` / `celsius`）
   - `to_unit`：目标单位（同上）
   - 可在 `category` 明确类别（length / weight / temperature / area），单位歧义时必填
3. 结果取合理精度（最多 4 位小数），并附上换算关系说明。

## 回复模板

- 成功：`{value} {from_display} = {result} {to_display}`
- 失败（单位不支持/无法换算）：给出支持的单位类别与示例，不臆造数值。

## 边界

- 只做单位换算，不做汇率、日期、进制等其他换算，避免误用工具。
- 温度换算涉及偏移量，直接交给工具，不要在提示词中自行推导。
