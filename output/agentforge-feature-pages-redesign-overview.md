# AgentForge 功能页视觉重构与乱码修复

## 本轮完成

在不修改接口、路由、鉴权、Pinia 状态与业务行为的前提下，完成五个功能页的视觉升级：

- 工具与技能：能力编目式卡片、光谱状态线、稳定操作轨。
- 知识库：检索光台与知识档案室双栏结构。
- 可观测：信号化统计卡、生命线趋势与更清晰的审计表。
- 智能体：角色档案式卡片与能力绑定层级。
- 模型管理：模型编目与连接状态控制台。

## 工具与技能乱码修复

“编辑 / 停用 / 删除”文本在源代码和开发服务返回内容中均确认是 UTF-8 正常中文。为避免浏览器字体继承、行高和图标文本混排导致的异常显示，本轮将这组操作重构为：

- 语义化的独立文字容器 `action-label`；
- 显式指定中文界面字体、行高与抗锯齿渲染；
- 加入无障碍 `aria-label`；
- 统一图标、启停状态点与按钮最小高度。

这同时保留了原有的编辑、启停、删除事件处理和 API 调用。
